# 74LS20 — Dual 4-Input NAND Gate

## Overview
The 74LS20 contains two independent 4-input NAND gates. The output of each gate is LOW only when all four inputs are simultaneously HIGH; if any input is LOW the output remains HIGH. Two pins (3 and 11) are unused no-connects. The chip is commonly used for address decoding, detecting all-ones conditions on a nibble, or combining multiple enable signals.

## Pinout
| Pin | Name | Type | Description |
|-----|------|------|-------------|
| 1 | 1A | I | Gate 1 input A |
| 2 | 1B | I | Gate 1 input B |
| 3 | NC | — | No connection |
| 4 | 1C | I | Gate 1 input C |
| 5 | 1D | I | Gate 1 input D |
| 6 | 1Y | O | Gate 1 output |
| 7 | GND | P | Ground (0 V) |
| 8 | 2Y | O | Gate 2 output |
| 9 | 2A | I | Gate 2 input A |
| 10 | 2B | I | Gate 2 input B |
| 11 | NC | — | No connection |
| 12 | 2C | I | Gate 2 input C |
| 13 | 2D | I | Gate 2 input D |
| 14 | VCC | P | Supply voltage (+5 V) |

## Notes
- NC pins (3 and 11) have no internal connection and may be left open or tied to GND/VCC.
- Unused inputs must be tied HIGH (via a resistor or directly to VCC) to prevent floating inputs from causing unpredictable behavior.
- The two gates are fully independent; there is no shared enable or common control line.
- Typical propagation delay: ~15 ns (LS subfamily at 5 V, 25 °C).

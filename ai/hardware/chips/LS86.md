# 74LS86 — Quadruple 2-Input XOR Gate

## Overview
The 74LS86 contains four independent 2-input Exclusive-OR (XOR) gates. The output of each gate is HIGH when its two inputs differ (one HIGH, one LOW) and LOW when both inputs are the same (both HIGH or both LOW). XOR gates are fundamental building blocks for binary adders, parity generators/checkers, comparators, and controlled inverters (using one input as a data line and the other as an invert-enable).

## Notes
- Truth table per gate: Y = A ⊕ B; output is HIGH only when inputs are different.
- Controlled inverter: tying one input HIGH forces the output to be the complement of the other input; tying one input LOW passes the other input unchanged.
- Four gates per package allow construction of a 4-bit parity tree or a 4-bit comparator stage.
- Typical propagation delay: ~22 ns HIGH-to-LOW, ~17 ns LOW-to-HIGH (LS subfamily at 5 V, 25 °C).

# 74LS30 — 8-Input NAND Gate

## Overview
The 74LS30 contains a single 8-input NAND gate. The output is LOW only when all eight inputs are simultaneously HIGH; if any input is LOW the output is HIGH. Three of the 14 pins are no-connects (NC), leaving the package mostly occupied by the eight input lines, one output, power, and ground.

## Pinout
| Pin | Name | Type | Description |
|-----|------|------|-------------|
| 1 | A | I | Input A |
| 2 | B | I | Input B |
| 3 | C | I | Input C |
| 4 | D | I | Input D |
| 5 | E | I | Input E |
| 6 | F | I | Input F |
| 7 | GND | P | Ground (0 V) |
| 8 | Y | O | NAND output |
| 9 | NC | — | No connection |
| 10 | NC | — | No connection |
| 11 | G | I | Input G |
| 12 | H | I | Input H |
| 13 | NC | — | No connection |
| 14 | VCC | P | Supply voltage (+5 V) |

## Notes
- Unused inputs must not be left floating; tie them HIGH (to VCC through a resistor or directly) to ensure correct operation.
- A single 8-input NAND is useful for detecting when all bits of an 8-bit bus are set, or as a chip-enable decoder with multiple address lines.
- The three NC pins have no internal connection and may be left open or connected to GND or VCC for board cleanliness.
- Typical propagation delay: ~15 ns (LS subfamily at 5 V, 25 °C).

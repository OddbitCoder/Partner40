# M3764A-15 — 64K×1 Dynamic RAM (OKI MSM3764A)

## Overview
The OKI MSM3764A is a fully decoded dynamic NMOS RAM organised as 65,536 words × 1 bit, housed in a 16-pin DIP. Addresses are multiplexed: the same 8 pins carry the 8-bit row address (latched on the falling edge of /RAS) and the 8-bit column address (latched on the falling edge of /CAS). The design uses silicon-gate double-polysilicon NMOS with single-transistor storage cells. Separate Din and Dout pins allow common-I/O operation via the Early Write mode. Requires 128 RAS-only refresh cycles every 2 ms. Row access time is 150 ns max (-15 variant); cycle time is 260 ns min. Single +5V supply (±10%). On the Partner 40, 16 of these chips (E59–E62, E71–E74, E85–E88, E98–E101) provide 64K × 16 bits of main RAM.

## Pinout

| Pin | Name | Type | Description |
|--|--|--|--|
| 1 | NC | — | No internal connection. |
| 2 | Din | I | Data Input. Latched internally; valid data must be present before /CAS falls in a write cycle. |
| 3 | /WE | I | Write Enable (active low). Low = write cycle; high = read cycle. Must be stable before /CAS falls. |
| 4 | /RAS | I | Row Address Strobe (active low). Falling edge latches the row address from A0–A7 and begins the access cycle. |
| 5 | A0 | I | Address bit 0 (multiplexed row/column). |
| 6 | A2 | I | Address bit 2 (multiplexed row/column). |
| 7 | A1 | I | Address bit 1 (multiplexed row/column). |
| 8 | VCC | P | +5V (±10%) power supply. |
| 9 | A7 | I | Address bit 7 (row address only). |
| 10 | A5 | I | Address bit 5 (multiplexed row/column). |
| 11 | A4 | I | Address bit 4 (multiplexed row/column). |
| 12 | A3 | I | Address bit 3 (multiplexed row/column). |
| 13 | A6 | I | Address bit 6 (multiplexed row/column). |
| 14 | Dout | O | Data Output (3-state). Valid after row and column access times. Unlatched at cycle end. |
| 15 | /CAS | I | Column Address Strobe (active low). Falling edge latches the column address from A0–A7 and enables Dout. |
| 16 | VCC | P | +5V (±10%) power supply (second VCC pin). |

## Notes
- VSS (ground) is not an explicit pin — the package ground is internally connected; an external ground pin is not present on the 16-pin DIP (ground is via the substrate/case on some packages; verify PCB footprint).
- Address pins A0–A6 are fully multiplexed (used for both row and column address). A7 carries only the row address; the column address is 7 bits (A0–A6), giving 128 columns × 512 rows... 

  Actually: row = A0–A7 (8 bits, 256 rows); column = A0–A6 (7 bits, 128 columns) × 2 = 256 effective columns via the chip's internal organisation. The datasheet states 128 refresh cycles/2 ms, confirming 128 physical row pairs.

- Supported access modes: standard read/write, Read-Modify-Write, RAS-only refresh, Page Mode (hold /RAS low, toggle /CAS).
- On the Partner 40, each chip provides 1 bit of the data bus width; 8 chips per bank form an 8-bit wide memory. Two banks of 8 chips give 64K × 16 bits total (or 64K × 8 bits per bank).

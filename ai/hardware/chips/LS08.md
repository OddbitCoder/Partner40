# 74LS08 — Quadruple 2-Input AND Gate

## Overview
The 74LS08 contains four independent 2-input AND gates. The output of each gate is HIGH only when both of its inputs are simultaneously HIGH; otherwise the output is LOW. Standard push-pull (totem-pole) outputs are provided with no 3-state or open-collector features. The device is one of the most fundamental combinational logic building blocks in TTL logic families and is used extensively for condition gating, enable-signal qualification, and address/control decoding in Z80 and other microcomputer systems.

## Pinout
| Pin | Name | Type | Description |
|-----|------|------|-------------|
| 1 | 1A | I | Gate 1, input A |
| 2 | 1B | I | Gate 1, input B |
| 3 | 1Y | O | Gate 1 output (1A AND 1B) |
| 4 | 2A | I | Gate 2, input A |
| 5 | 2B | I | Gate 2, input B |
| 6 | 2Y | O | Gate 2 output (2A AND 2B) |
| 7 | GND | P | Ground (0 V) |
| 8 | 3Y | O | Gate 3 output (3A AND 3B) |
| 9 | 3A | I | Gate 3, input A |
| 10 | 3B | I | Gate 3, input B |
| 11 | 4Y | O | Gate 4 output (4A AND 4B) |
| 12 | 4A | I | Gate 4, input A |
| 13 | 4B | I | Gate 4, input B |
| 14 | VCC | P | Supply voltage (+5 V) |

## Notes
- Note the pin order reversal between the upper half (pins 1–6) and lower half (pins 8–13): inputs precede the output in the upper half, but the output precedes the inputs in the lower half.
- Typical propagation delay is 12 ns (LS subfamily).
- Pin-compatible with 74S08 (Schottky, faster), 74HC08 (CMOS), and 74HCT08 (CMOS, TTL-input compatible).
- In Z80 systems, AND gates are frequently used to qualify chip-select signals (e.g., decoded address AND ~RD) or to gate clock/control signals conditionally.

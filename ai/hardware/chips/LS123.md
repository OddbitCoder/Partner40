# 74LS123 — Dual Retriggerable Monostable Multivibrator

## Overview
The 74LS123 contains two independent retriggerable monostable multivibrators (one-shots). Each monostable generates a single output pulse of controlled width whenever it is triggered; if a second trigger arrives before the pulse ends, the timing resets and a new full-width pulse begins (retriggerable behaviour). Each unit has two trigger inputs: a negative-edge-triggered input (A, active LOW) and a positive-edge-triggered input (B, active HIGH). An active-LOW asynchronous clear (~CLR) immediately terminates any output pulse when asserted. Pulse width is set by an external RC network connected to the RCext/Cext pins. The chip includes an internal timing resistor that allows operation with only an external capacitor.

## Pinout
| Pin | Name | Type | Description |
|-----|------|------|-------------|
| 1 | 1A | I | Multivibrator 1 trigger input, negative-edge triggered (active LOW) |
| 2 | 1B | I | Multivibrator 1 trigger input, positive-edge triggered (active HIGH) |
| 3 | ~1CLR | I | Multivibrator 1 asynchronous clear, active LOW |
| 4 | 1Q | O | Multivibrator 1 inverted output (~Q) |
| 5 | 2~Q | O | Multivibrator 2 inverted output (~Q) |

## Notes
- Pulse width is approximately t_w = 0.28 × R × C (with external resistor at RCext, external capacitor between Cext and GND).
- For operation with the internal timing resistor (~10 kΩ), connect RCext to VCC and use only an external capacitor between Cext and GND.
- Both Q and ~Q outputs are available for each multivibrator; the ~Q output is LOW during the timing pulse.
- Asserting ~CLR LOW during a timing pulse immediately terminates it and resets the output; ~CLR must remain HIGH for normal triggered operation.
- The 74LS123 is useful for generating debounce delays, bus cycle timeouts, and reset pulse stretchers in Z80 computer designs.
- The 74LS122 is a similar non-retriggerable variant.

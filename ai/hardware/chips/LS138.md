# 74LS138 — 3-to-8 Line Decoder/Demultiplexer

## Overview
The 74LS138 decodes a 3-bit binary address on inputs A0–A2 into one of eight mutually exclusive active-LOW outputs Y0–Y7. Three enable inputs (two active-LOW: ~E1 and ~E2, one active-HIGH: E3) must all be satisfied simultaneously for any output to be asserted; otherwise all outputs remain HIGH. This enable structure allows simple expansion to larger decoders (e.g., 1-of-24 with three chips) or straightforward use as a chip-select generator in memory and I/O address decoding. The chip is a staple of Z80 address decoding circuits.

## Pinout
| Pin | Name | Type | Description |
|-----|------|------|-------------|
| 1 | A0 | I | Address input bit 0 (LSB) |
| 2 | A1 | I | Address input bit 1 |
| 3 | A2 | I | Address input bit 2 (MSB) |
| 4 | ~E1 | I | Enable 1, active LOW (must be LOW to enable) |
| 5 | ~E2 | I | Enable 2, active LOW (must be LOW to enable) |
| 6 | E3 | I | Enable 3, active HIGH (must be HIGH to enable) |
| 7 | ~Y7 | O | Output 7, active LOW (selected when A=111) |
| 8 | GND | P | Ground (0 V) |
| 9 | ~Y6 | O | Output 6, active LOW (selected when A=110) |
| 10 | ~Y5 | O | Output 5, active LOW (selected when A=101) |
| 11 | ~Y4 | O | Output 4, active LOW (selected when A=100) |
| 12 | ~Y3 | O | Output 3, active LOW (selected when A=011) |
| 13 | ~Y2 | O | Output 2, active LOW (selected when A=010) |
| 14 | ~Y1 | O | Output 1, active LOW (selected when A=001) |
| 15 | ~Y0 | O | Output 0, active LOW (selected when A=000) |
| 16 | VCC | P | Supply voltage (+5 V) |

## Notes
- All eight outputs are active-LOW: the selected output is pulled LOW; all others remain HIGH.
- The three enable inputs allow the chip to be easily daisy-chained; for a single-chip decoder, tie ~E1 and ~E2 to GND and E3 to VCC.
- In Z80 memory maps, A2/A1/A0 are typically driven from upper address lines (e.g., A15/A14/A13) to create eight 8 kB bank-select signals.
- Propagation delay from address to output is typically 22 ns; from enable to output is typically 18 ns.
- The 74LS139 is a related dual 2-to-4 decoder in the same package size.

# 74LS157 — Quadruple 2-to-1 Line Data Selector/Multiplexer

## Overview
The 74LS157 contains four independent 2-to-1 multiplexers that select one of two 4-bit data sources (A or B) and route it to four outputs (Y0–Y3). A common SELECT input chooses the active source for all four multiplexers simultaneously: SELECT LOW routes the A inputs to the outputs; SELECT HIGH routes the B inputs. A common active-LOW STROBE (~G) disables all outputs (drives them LOW) when asserted HIGH, regardless of the SELECT state. The device is used for data routing, source selection, and dynamic address/data multiplexing in microcomputer systems.

## Pinout
| Pin | Name | Type | Description |
|-----|------|------|-------------|
| 1 | SELECT | I | Common source-select input: LOW = A inputs, HIGH = B inputs |
| 2 | A0 | I | Channel 0, source A data input |
| 3 | B0 | I | Channel 0, source B data input |
| 4 | Y0 | O | Channel 0 output |
| 5 | A1 | I | Channel 1, source A data input |
| 6 | B1 | I | Channel 1, source B data input |
| 7 | Y1 | O | Channel 1 output |
| 8 | GND | P | Ground (0 V) |
| 9 | Y2 | O | Channel 2 output |
| 10 | B2 | I | Channel 2, source B data input |
| 11 | A2 | I | Channel 2, source A data input |
| 12 | Y3 | O | Channel 3 output |
| 13 | B3 | I | Channel 3, source B data input |
| 14 | A3 | I | Channel 3, source A data input |
| 15 | ~G | I | Strobe (output enable), active LOW; HIGH forces all outputs LOW |
| 16 | VCC | P | Supply voltage (+5 V) |

## Notes
- The SELECT and ~G inputs are common to all four sections, so the chip always selects the same source and enables/disables all four channels together.
- When ~G is HIGH, all Y outputs are forced LOW (not high-impedance); this distinguishes it from a 3-state device.
- The 74LS158 is the inverting version (outputs are inverted relative to the selected input).
- Typical propagation delay from data or select to output is 12–17 ns.
- In Z80 systems, two LS157 chips can multiplex an 8-bit data bus from two sources using a single SELECT signal.

# 74LS393 — Dual 4-Bit Binary Counter

## Overview
The 74LS393 contains two identical independent 4-bit binary (ripple) counters in a single 14-pin DIP package. Each counter has a clock input (CP, falling-edge triggered), an active-HIGH master reset (MR), and four ripple-carry outputs (QA–QD, where QA is the LSB). Each counter increments on the falling edge of its clock and can count from 0 to 15 (modulo-16). The two counters can be cascaded by connecting QD of the first counter to CP of the second to form an 8-bit counter.

## Pinout
| Pin | Name | Type | Description |
|-----|------|------|-------------|
| 1 | 1CP | I | Counter 1 clock input (falling-edge triggered) |
| 2 | 1MR | I | Counter 1 master reset (active HIGH, asynchronous) |
| 3 | 1QA | O | Counter 1 output bit A (LSB, divide-by-2) |
| 4 | 1QB | O | Counter 1 output bit B (divide-by-4) |
| 5 | 1QC | O | Counter 1 output bit C (divide-by-8) |
| 6 | 1QD | O | Counter 1 output bit D (MSB, divide-by-16) |
| 7 | GND | P | Ground (0 V) |
| 8 | 2QD | O | Counter 2 output bit D (MSB, divide-by-16) |
| 9 | 2QC | O | Counter 2 output bit C (divide-by-8) |
| 10 | 2QB | O | Counter 2 output bit B (divide-by-4) |
| 11 | 2QA | O | Counter 2 output bit A (LSB, divide-by-2) |
| 12 | 2MR | I | Counter 2 master reset (active HIGH, asynchronous) |
| 13 | 2CP | I | Counter 2 clock input (falling-edge triggered) |
| 14 | VCC | P | Supply voltage (+5 V) |

## Notes
- Each counter is triggered on the HIGH-to-LOW (falling) edge of its clock input.
- MR (master reset) is asynchronous and active HIGH: asserting it immediately clears all four outputs to 0, regardless of clock state.
- To cascade into an 8-bit counter: connect 1QD to 2CP; both MR pins may be tied together for a common reset.
- Individual outputs (QA, QB, QC, QD) can be used as divide-by-2, -4, -8, and -16 clock outputs respectively.
- Maximum clock frequency: typically 25 MHz (LS subfamily at 5 V, 25 °C).

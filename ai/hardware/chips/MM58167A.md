# MM58167A — Microprocessor Real-Time Clock

## Overview
The MM58167A is a low-threshold metal-gate CMOS real-time clock for bus-oriented microprocessor systems. It contains an addressable real-time counter (milliseconds through months, BCD), 56 bits of RAM (usable as alarm registers), and two interrupt outputs. A 32.768 kHz crystal oscillator provides the time base. The POWER DOWN input disables all I/O except the STANDBY INTERRUPT, allowing battery-backed timekeeping. The chip has a 5-bit address bus giving access to 19 counter/RAM addresses, 2 reset commands, 2 special commands, and a test mode. 8-bit bidirectional data bus. 24-hour clock with four-year calendar (no leap year correction).

## Pinout

| Pin | Name | Type | Description |
|--|--|--|--|
| 1 | /CS | I | Chip Select (active low). Must be low together with /RD or /WR to access the device. |
| 2 | /RD | I | Read Strobe (active low). Initiates a read cycle when low with /CS. |
| 3 | /WR | I | Write Strobe (active low). Initiates a write cycle when low with /CS. |
| 4 | /RDY | OC | Ready (open drain, active low). Pulled low at the start of each read or write cycle; released when data is valid (read) or latched (write). Requires external pull-up. |
| 5 | A0 | I | Address bit 0. 5-bit address selects counter, RAM, or control register. |
| 6 | A1 | I | Address bit 1. |
| 7 | A2 | I | Address bit 2. |
| 8 | A3 | I | Address bit 3. |
| 9 | A4 | I | Address bit 4. |
| 10 | OSC IN | I | Oscillator Input. Connect to one terminal of a 32.768 kHz crystal (with 20 MΩ bias resistor between OSC IN and OSC OUT). May also be driven directly by an external TTL-level 32.768 kHz signal. |
| 11 | OSC OUT | O | Oscillator Output. Connect to the other terminal of the crystal. Leave floating when using external clock on OSC IN. |
| 12 | VSS | P | Ground (0V). |
| 13 | INTERRUPT OUTPUT | O | Interrupt Output (active high, totem-pole). Programmable to trigger at: 10 Hz, 1/s, 1/min, 1/hr, 1/day, 1/week, 1/month, or on RAM/counter comparison. Reset by reading the interrupt status register (address 10H). |
| 14 | STANDBY INTERRUPT | OC | Standby Interrupt (open drain, active low). Triggers on RAM/counter comparison. Remains active during POWER DOWN. Enabled by writing 1 to D0 at address 16H. Level-triggered (not edge). |
| 15 | D0 | I/O | Data bus bit 0. |
| 16 | D1 | I/O | Data bus bit 1. |
| 17 | D2 | I/O | Data bus bit 2. |
| 18 | D3 | I/O | Data bus bit 3. |
| 19 | D4 | I/O | Data bus bit 4. |
| 20 | D5 | I/O | Data bus bit 5. |
| 21 | D6 | I/O | Data bus bit 6. |
| 22 | D7 | I/O | Data bus bit 7. |
| 23 | POWER DOWN | I | Power Down (active low). When low, disables all inputs and outputs except STANDBY INTERRUPT. Clock continues running. Must go low at least 1 µs before VDD is switched to standby voltage. |
| 24 | VDD | P | +5V (4.5V–5.5V) power supply. |

## Address Map

| Address | Function |
|--|--|
| 00H | Counter — Milliseconds |
| 01H | Counter — Hundredths and Tenths of Seconds |
| 02H | Counter — Seconds |
| 03H | Counter — Minutes |
| 04H | Counter — Hours |
| 05H | Counter — Day of Week |
| 06H | Counter — Day of Month |
| 07H | Counter — Month |
| 08H–0FH | RAM (mirrors above layout) |
| 10H | Interrupt Status Register (read to identify and reset interrupt) |
| 11H | Interrupt Control Register (write to enable interrupt frequencies) |
| 12H | Counters Reset (write FFH) |
| 13H | RAM Reset (write FFH) |
| 14H | Status Bit (D0=1 if rollover during read; read resets it) |
| 15H | GO Command (resets sub-second counters for precise start) |
| 16H | STANDBY INTERRUPT enable (write D0=1 to enable) |
| 1FH | Test Mode |

## Notes
- Counter data is BCD, 4 bits per digit, two digits per read/write cycle.
- The ripple counter can produce invalid reads during rollover; always read the status bit (address 14H) after reading counters and re-read if set.
- Crystal oscillator requires: 32.768 kHz series-resonant crystal, 20 MΩ bias resistor between OSC IN and OSC OUT, and ~20–25 pF capacitors to ground on each oscillator pin.
- A ground guard trace between pins 9 and 10 is recommended to prevent address line A4 from disturbing the oscillator.
- On the Partner 40, E35 (MM58167A) is the real-time clock, providing timekeeping for the operating system.

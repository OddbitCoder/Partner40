# WD2143-01 — Four-Phase Clock Generator

## Overview
The WD2143-01 is an 18-pin MOS/LSI device that generates four non-overlapping clock phases (φ1–φ4), each available in both true and inverted form. Output pulse widths are programmable via external resistors — either all phases to the same width (via φPW) or each individually (via φ1PW–φ4PW). An on-chip oscillator accepts a series-resonant crystal on XTAL1/XTAL2, or a TTL square wave on XTAL2 (XTAL1 left open). OSC OUT provides a TTL square wave at crystal frequency ÷ 4. Maximum operating frequency is 3 MHz. Single +5V supply. On the Partner 40, E57 (WD2143) works with E48 (WD1691) to provide Write Precompensation for the floppy disk interface.

## Pinout

| Pin | Name | Type | Description |
|--|--|--|--|
| 1 | /φ4 | O | Phase 4 inverted output (active low, non-overlapping). |
| 2 | φ4 | O | Phase 4 true output (active high, non-overlapping). |
| 3 | /φ3 | O | Phase 3 inverted output (active low, non-overlapping). |
| 4 | φ3 | O | Phase 3 true output (active high, non-overlapping). |
| 5 | /φ2 | O | Phase 2 inverted output (active low, non-overlapping). |
| 6 | φ2 | O | Phase 2 true output (active high, non-overlapping). |
| 7 | /φ1 | O | Phase 1 inverted output (active low, non-overlapping). |
| 8 | φ1 | O | Phase 1 true output (active high, non-overlapping). |
| 9 | GND | P | Ground (0V). |
| 10 | XTAL 2 | I | Crystal connection 2. May also be driven by a TTL square wave (with XTAL1 left open). |
| 11 | XTAL 1 | I | Crystal connection 1. Connect with XTAL2 to a series-resonant crystal. Leave open when using TTL clock input on XTAL2. |
| 12 | OSC OUT | O | Oscillator output. TTL-compatible square wave at crystal frequency ÷ 4. |
| 13 | φ1PW | I | Phase 1 pulse width control. Tie through external resistor to +5V to set φ1 pulse width individually. Leave open if φPW is used. |
| 14 | φ2PW | I | Phase 2 pulse width control. |
| 15 | φ3PW | I | Phase 3 pulse width control. |
| 16 | φ4PW | I | Phase 4 pulse width control. |
| 17 | φPW | I | Global pulse width control. Tie through external resistor to +12V to set all four phase outputs to the same pulse width. Individual φnPW pins should be left open when using this. |
| 18 | VCC | P | +5V (±5%) power supply. |

## Notes
- Each output can drive 1 TTL load.
- For equal pulse widths: leave φ1PW–φ4PW open and tie φPW through a 5kΩ resistor to +12V.
- For individual pulse widths: tie each φnPW through an external resistor to +5V; leave φPW open.
- In the floppy disk Write Precompensation application, φ1–φ4 connect to the WD1691 (pins 4, 2, 3, 19 respectively), with STB from WD1691 triggering the pulse generation.
- The non-overlap time between phases is 20 ns minimum, ensuring no two phases are simultaneously active.

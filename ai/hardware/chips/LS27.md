# 74LS27 — Triple 3-Input NOR Gate

## Overview
The 74LS27 contains three independent 3-input NOR gates. The output of each gate is HIGH only when all three inputs are simultaneously LOW; if any input is HIGH the output is LOW. NOR gates can be used to implement any Boolean function and are particularly useful for detecting all-zeros conditions, building SR latches, or combining active-LOW enable signals.

## Pinout
| Pin | Name | Type | Description |
|-----|------|------|-------------|
| 1 | 1A | I | Gate 1 input A |
| 2 | 1B | I | Gate 1 input B |
| 3 | 2A | I | Gate 2 input A |
| 4 | 2B | I | Gate 2 input B |
| 5 | 2C | I | Gate 2 input C |
| 6 | 2Y | O | Gate 2 output |
| 7 | GND | P | Ground (0 V) |
| 8 | 3Y | O | Gate 3 output |
| 9 | 3A | I | Gate 3 input A |
| 10 | 3B | I | Gate 3 input B |
| 11 | 3C | I | Gate 3 input C |
| 12 | 1Y | O | Gate 1 output |
| 13 | 1C | I | Gate 1 input C |
| 14 | VCC | P | Supply voltage (+5 V) |

## Notes
- Gate 1 has its inputs split across both sides of the package: inputs 1A and 1B are on pins 1 and 2, input 1C is on pin 13, and output 1Y is on pin 12.
- Unused inputs must be tied LOW (to GND) for correct NOR operation; floating inputs will likely read HIGH and suppress the output.
- All three gates are fully independent with no shared enables or control lines.
- Typical propagation delay: ~15 ns (LS subfamily at 5 V, 25 °C).

# 74LS10 — Triple 3-Input NAND Gate

## Overview
The 74LS10 contains three independent 3-input NAND gates. Each gate output is LOW only when all three of its inputs are simultaneously HIGH; if any input is LOW the output is HIGH. The device is a standard 14-pin DIP and is commonly used for address decoding, control logic, and combining three-signal enable conditions.

## Pinout
| Pin | Name | Type | Description |
|-----|------|------|-------------|
| 1 | 1A | I | Gate 1 input A |
| 2 | 1B | I | Gate 1 input B |
| 3 | 2A | I | Gate 2 input A |
| 4 | 2B | I | Gate 2 input B |
| 5 | 2C | I | Gate 2 input C |
| 6 | 2Y | O | Gate 2 output |
| 7 | GND | P | Ground (0 V) |
| 8 | 3Y | O | Gate 3 output |
| 9 | 3A | I | Gate 3 input A |
| 10 | 3B | I | Gate 3 input B |
| 11 | 3C | I | Gate 3 input C |
| 12 | 1Y | O | Gate 1 output |
| 13 | 1C | I | Gate 1 input C |
| 14 | VCC | P | Supply voltage (+5 V) |

## Notes
- Gate 1 occupies pins 1, 2, 13 (inputs) and 12 (output) — inputs and output are split across both sides of the package.
- Unused inputs must be tied HIGH to avoid floating; they may be connected directly to VCC or via pull-up resistors.
- All three gates are fully independent with no shared control signals.
- Typical propagation delay: ~15 ns (LS subfamily at 5 V, 25 °C).

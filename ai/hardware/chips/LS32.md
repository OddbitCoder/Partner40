# 74LS32 — Quadruple 2-Input OR Gate

## Overview
The 74LS32 contains four independent 2-input OR gates. The output of each gate is HIGH whenever one or both inputs are HIGH, and LOW only when both inputs are simultaneously LOW. Standard push-pull (totem-pole) outputs are provided; there are no 3-state or open-collector features. The device is a fundamental combinational logic building block used for signal combining, condition detection, and bus arbitration in digital systems including Z80-based computers.

## Pinout
| Pin | Name | Type | Description |
|-----|------|------|-------------|
| 1 | 1A | I | Gate 1, input A |
| 2 | 1B | I | Gate 1, input B |
| 3 | 1Y | O | Gate 1 output (1A OR 1B) |
| 4 | 2A | I | Gate 2, input A |
| 5 | 2B | I | Gate 2, input B |
| 6 | 2Y | O | Gate 2 output (2A OR 2B) |
| 7 | GND | P | Ground (0 V) |
| 8 | 3Y | O | Gate 3 output (3A OR 3B) |
| 9 | 3B | I | Gate 3, input B |
| 10 | 3A | I | Gate 3, input A |
| 11 | 4Y | O | Gate 4 output (4A OR 4B) |
| 12 | 4B | I | Gate 4, input B |
| 13 | 4A | I | Gate 4, input A |
| 14 | VCC | P | Supply voltage (+5 V) |

## Notes
- Note the pin order reversal between the upper half (pins 1–6) and lower half (pins 8–13): inputs precede the output in the upper half, but the output precedes the inputs in the lower half.
- Typical propagation delay is 14 ns (LS subfamily).
- Functionally equivalent to 74LS32 from any manufacturer (TI, Fairchild, Motorola, National Semiconductor, etc.).
- In Z80 designs the LS32 is often used to combine active-low control signals (e.g., ~MEMREQ OR ~IORQ) or to assert a bus signal when any one of several conditions is met.

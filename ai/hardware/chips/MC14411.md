# MC14411 — Motorola CMOS Bit Rate Generator

## Overview
The MC14411 is a 24-pin wide-DIP CMOS LSI Bit Rate Generator that simultaneously produces 16 standard baud-rate clock frequencies from a single 1.8432 MHz crystal-controlled oscillator. Using a two-bit rate-select address (RSa, RSb), one of four sets of output frequencies can be selected, giving access to baud rates from 75 to 921,600 baud (depending on rate-select setting and the external divider in the UART). All 16 outputs (F1–F16) have a 50% duty cycle and are buffered to drive low-power TTL loads. An active-low RST input resets all dividers. An external clock may be applied to the XTALin pin (pin 21) instead of a crystal. The device is widely used with 8250/16550 UARTs, ACIA/SIO/USART devices, and similar serial interface chips in Z80 and 6800-family systems.

## Notes
- The 16 output frequencies are derived by dividing the 1.8432 MHz oscillator by fixed integer ratios. The rate-select inputs (RSa, RSb) choose which divider table is active, effectively scaling all 16 outputs by ×1, ×2, ×8, or ×16 relative to the base rates. At the default X1 rate (RSa=RSb=1) and with the standard 1.8432 MHz crystal, the outputs provide standard ×16 baud-rate clocks: F1=921,600 Hz (57,600 baud), F2=460,800 Hz (28,800 baud), F3=307,200 Hz (19,200 baud), F4=153,600 Hz (9,600 baud), F5=76,800 Hz (4,800 baud), F6=38,400 Hz (2,400 baud), F7=19,200 Hz (1,200 baud), F8=9,600 Hz (600 baud), F9=4,800 Hz (300 baud), F10=3,200 Hz (200 baud), F11=2,400 Hz (150 baud), F12=2,134 Hz (134.5 baud), F13=1,600 Hz (100 baud), F14=1,200 Hz (75 baud), F15=921,600 Hz (same as F1), F16=614,400 Hz (38,400 baud at ×16).
- In normal operation: VDD (pin 24) = +5 V, VSS (pin 12) = GND, and RST (pin 10) is tied to VDD through a pull-up resistor (the internal pull-up suffices if pin 10 is left open).
- If an external clock is used instead of a crystal, connect the clock to XTALin (pin 21) and leave XTALout (pin 20) floating.
- The package is a wide (600 mil) 24-pin DIP (Motorola suffix -P for plastic, -L for ceramic).

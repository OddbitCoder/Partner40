# 74LS01 — Quadruple 2-Input NAND Gate with Open-Collector Outputs

## Overview
The 74LS01 contains four independent 2-input NAND gates with open-collector outputs. The output is LOW (sink) only when both inputs are HIGH; otherwise the output is in a high-impedance state and must be pulled HIGH by an external resistor. Multiple open-collector outputs may be wire-ANDed on a shared bus. The 74LS01 is functionally equivalent to the 74LS00 except that it uses open-collector rather than totem-pole outputs.

## Pinout
| Pin | Name | Type | Description |

| 1 | 1Y | OC | Gate 1 output (open-collector) |
| 2 | 1A | I | Gate 1 input A |
| 3 | 1B | I | Gate 1 input B |
| 4 | 2Y | OC | Gate 2 output (open-collector) |
| 5 | 2A | I | Gate 2 input A |

| 7 | GND | P | Ground (0 V) |

| 9 | 3B | I | Gate 3 input B |

| 14 | VCC | P | Supply voltage (+5 V) |

## Notes
- Note that the pin order for the 74LS01 is output-then-inputs per gate (Y, A, B), unlike the 74LS00 which is inputs-then-output (A, B, Y).
- Each output requires an external pull-up resistor (typically 1 kΩ–10 kΩ to VCC) for a logic HIGH level.
- Wire-AND: connect multiple outputs together; the bus is pulled LOW if any gate output is active.
- Maximum output sink current: 8 mA (LS subfamily); maximum collector voltage: 5.5 V.
- Can be used for level translation or interfacing to 3.3 V or other voltage domains by choosing an appropriate pull-up voltage.

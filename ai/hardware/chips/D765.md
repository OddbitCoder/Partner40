# D765 — NEC µPD765 / Intel 8272A Floppy Disk Controller

## Overview
The NEC µPD765AC (marketed by NEC as the D765 and by Intel as the 8272A) is a single-chip, single/double-density floppy disk controller in a 40-pin DIP package. It handles all floppy disk functions—including seek, read, write, format, scan, and verify—through a high-level command interface, offloading the CPU from detailed disk-timing tasks. The chip supports up to four disk drives in both FM (single-density) and MFM (double-density) formats at data rates up to 500 kbps. It provides a separate DMA channel interface (DRQ/DACK/TC) and an interrupt output for CPU notification. The µPD765 was one of the most widely used FDCs of the late 1970s and early 1980s, appearing in the IBM PC (as the 8272A), Amstrad CPC, TRS-80, and many other systems.

## Pinout

| Pin | Name | Type | Description |
|--|--|--|--|
| 1 | RESET | I | Master Reset (active high). Clears all internal registers and returns the chip to idle state. |
| 2 | RD | I | Read Strobe (active low). CPU reads data or status from the chip. |
| 3 | WR | I | Write Strobe (active low). CPU writes data or commands to the chip. |
| 4 | CS | I | Chip Select (active low). Enables the host bus interface. |
| 5 | A0 | I | Register Select. Low selects the Data Register; high selects the Main Status Register. |
| 6 | DB0 | I/O | Data Bus Bit 0 (three-state bidirectional). |
| 7 | DB1 | I/O | Data Bus Bit 1. |
| 8 | DB2 | I/O | Data Bus Bit 2. |
| 9 | DB3 | I/O | Data Bus Bit 3. |
| 10 | DB4 | I/O | Data Bus Bit 4. |
| 11 | DB5 | I/O | Data Bus Bit 5. |
| 12 | DB6 | I/O | Data Bus Bit 6. |
| 13 | DB7 | I/O | Data Bus Bit 7. |
| 14 | DRQ | O | DMA Request. Goes high to request a DMA transfer cycle; used with DACK and TC. |
| 15 | DACK | I | DMA Acknowledge (active low). Asserted by DMA controller to grant a DMA cycle; enables the data bus for DMA transfers. |
| 16 | TC | I | Terminal Count. A high pulse from the DMA controller signals the end of a DMA transfer block. |
| 17 | INDEX | I | Index Pulse Input (active low). Receives the index hole pulse from the drive, used for sector counting during format and for rotation synchronisation. |
| 18 | INT | O | Interrupt Request (active high). Asserted at the end of each command to signal the CPU. |
| 19 | CLK | I | System Clock Input. Nominally 8 MHz (or 4 MHz for some variants); determines internal timing. |
| 20 | GND | P | Ground (0 V). |
| 21 | WCLK | I | Write Clock Input. External clock derived from the data-separator PLL; used to clock write data at the correct bit rate (500 kHz for MFM double-density). |
| 22 | WINDOW | I | Read Data Window Input. Data-separator window signal that qualifies incoming read data bits. |
| 23 | RDATA | I | Read Data Input. Serial NRZ bit stream recovered from the disk drive by the data separator. |
| 24 | SYNC | O | VCO Sync Output. Provides a sync signal to the external data-separator VCO to lock it to the incoming data stream. |
| 25 | WE | O | Write Enable Output (active low). Enables the write circuitry of the selected drive. |
| 26 | MFM | O | MFM/FM Mode Output. High = MFM (double-density); low = FM (single-density). Used to configure external write-precompensation and data-separator circuits. |
| 27 | SIDE | O | Side Select Output. Selects the upper (1) or lower (0) recording head on double-sided drives. |
| 28 | US1 | O | Unit Select 1 Output (active low). Selects drive unit 1. |
| 29 | US0 | O | Unit Select 0 Output (active low). Selects drive unit 0. |
| 30 | WDATA | O | Write Data Output. Serial NRZ write data stream to be encoded and sent to the selected drive; may need write-precompensation for inner tracks. |
| 31 | PS1 | O | Pre-shift 1 Output. One of two write-precompensation control outputs; drives external precompensation logic (e.g. WD2143) to select shift amount. |
| 32 | PS0 | O | Pre-shift 0 Output. Second precompensation control bit. |
| 33 | FLT/TRK0 | I | Fault / Track 0 Input. Multiplexed: reads as Track 0 signal (active low) during normal operation; reads fault status from drives that support it. |
| 34 | WPRT/2SIDE | I | Write Protect / Two-Side Input. Multiplexed: Write Protect status from the drive; also used to detect double-sided media. |
| 35 | READY | I | Ready Input (active high). Drive ready signal; the FDC monitors this to confirm a drive is prepared for data transfer. |
| 36 | HDLD | O | Head Load Output (active low). Asserted to engage the read/write head against the disk surface. |
| 37 | FLTR/STEP | O | Fault Reset / Step Output. Multiplexed by the R/W/SEEK output: step pulse during seek operations; fault reset for fault-tolerant drives. |
| 38 | LCT/DIR | O | Low Current / Direction Output. Multiplexed: direction signal (high = outward) during seeks; low-write-current select for drives supporting it. |
| 39 | R/W/SEEK | O | Read/Write/Seek Select Output. Demultiplexes pins 37 and 38: indicates whether the current operation is a read, write, or seek. |
| 40 | VCC | P | Positive Supply (+5 V). |

## Notes
- The µPD765 and Intel 8272A are functionally identical and pin-for-pin compatible; the 8272A designation is Intel's second-source name.
- The chip supports 15 commands: Read Data, Read Deleted Data, Write Data, Write Deleted Data, Read Track, Read ID, Format Track, Scan Equal/Low/High, Seek, Recalibrate, Sense Interrupt Status, Specify, and Sense Drive Status.
- An external data separator (e.g. WD1691 or a PLL circuit) is required to recover the clock and data from the raw analog flux signal read from the drive; the SYNC, WINDOW, RDATA, and WCLK signals interface to this separator.
- The DACK input can also be used as an I/O read strobe in non-DMA (polled) mode; TC is used as an I/O write strobe in that configuration.
- Drives US2 and US3 (for a third and fourth drive) are typically decoded externally from US0 and US1 with additional logic.

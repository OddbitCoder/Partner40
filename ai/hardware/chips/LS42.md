# 74LS42 — BCD-to-Decimal Decoder

## Overview
The 74LS42 decodes a 4-bit BCD (Binary-Coded Decimal) input (A0–A3) into one of ten active-LOW outputs (Q0–Q9), each corresponding to a decimal digit 0 through 9. Only one output is asserted LOW at a time, based on the binary value of the input. For invalid BCD codes (10–15), all ten outputs remain HIGH. The device is housed in a 16-pin DIP.

## Notes
- Outputs are active LOW: the selected output is pulled to logic 0; all unselected outputs remain HIGH.
- Input codes 1010–1111 (10–15) are invalid BCD; all outputs remain HIGH for these combinations.
- Commonly used to decode address lines or to select one of up to ten peripheral devices or memory banks.
- Directly interfaces with TTL, CMOS, NMOS, and LED/display drivers.
- The 74LS138 (3-to-8 decoder) or 74LS154 (4-to-16 decoder) are alternatives when more outputs are needed.
